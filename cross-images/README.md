# cross-images

Компонент общего репозитория granio-tools.

**Исходник:** https://github.com/fyne-io/fyne-cross-images.
**Цель:** Рецепты контейнеров кросс-компиляции Granio.

История Git и имеющиеся лицензии сохранены.
Предыдущая документация — [UPSTREAM.md](UPSTREAM.md).

Сборка локальных образов из этого каталога:

```sh
make base linux
```

Используется пространство образов `ghcr.io/uzer007-admin/granio-cross`.
Для другого реестра задайте `REPOSITORY=...`; публикация выполняется отдельно.
До первой сборки или публикации готовые образы Granio могут отсутствовать.
